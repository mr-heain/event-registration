# 📋 Event Registration

A client-side event registration web app built with HTML, CSS, and JavaScript. Users can fill out a registration form, which validates inputs and displays a live list of all registered participants.

🔗 **[Live Demo](https://mr-heain.github.io/event-registration)**

---

## ✨ Features

- Form validation — checks for empty fields and correct input format
- Live registration list — shows all registered participants on the same page
- Clean, minimal UI
- Pure frontend — no backend, no database

> **Note:** Registrations reset on page reload since there's no server-side storage. This is intentional for a frontend-only project.
